1. In switchGymFighter(), I made an integer named int switch and set it to
   rand() % otherGyms, where otherGyms was 2. The word switch had an error
   that said "expected an identifier", so I searched up and learned that I
   can't name a variable switch since there's already something in C++ that
   is called switch and has that named reserved. The fix was just changing the
   name to switchChance.
2. The parameters in the switchGymFighter() prototype versus the actual
   function were different, which returned an error. The fix was just making
   sure they were both the same, since I copy-pasted the format of the prototype
   from another function.
3. The output after a fighter switches gyms messed up the format of the time
   interval counter. The fix was just adding a \n at the end of the couts in
   switchGymFighter().
4. After a fighter recovers from injury, the console sometimes outputs that
   they recovered from injury twice. That was because my recoverFighter()
   went through the whole list of that gym's fighters and then printed output
   the recovery message if the name was found. Thing is, if there was two of
   the same name in the same gym at different levels, it would print twice. The
   fix was just changing it so that not all experience levels are went through.
   I do worry, though, if there might be a bug if there are multiple of the
   same name in one experience level.
